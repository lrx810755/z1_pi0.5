# 杯子纠偏数据集要求

保存日期：2026-10-26。用户要求：先保存纠偏需求，当前先录制杯子基础集，4行×5列、每格20条，共400条完整成功示范。纠偏集本轮不启动，具体条数未指定。

## 已确定的纠偏覆盖范围

1. **接近过程中的位置和姿态恢复**：覆盖左偏、右偏、进深不足、过近、越过目标和姿态偏离；较大偏差先恢复至合适接近位，再进入抓取位置。偏移使用明确定义的夹爪局部坐标或世界坐标，不能将局部Z直接当作世界高度。
2. **对位到闭爪的阶段切换**：覆盖接近但持续张爪、对位后停顿及闭爪延迟；包含继续对齐和已经就绪应闭爪的不同状态，完整验证闭爪与离桌。
3. **杯子被推移后的重新定位**：覆盖杯子实际位移后的退让、观察、对齐和抓取。必须记录真实新杯位；准备阶段平移模拟与夹爪真实推移分开标记，不能混为同一种恢复。
4. **低位接近与桌面间隙恢复**：在碰桌前的可恢复状态接管，调整高度、姿态、路径后重新接近；保持碰桌保护，不使用真实穿入状态作为正常成功示范。
5. **夹持确认与重抓**：覆盖夹偏、单指接触、离桌不足、倾斜或滑移后的恢复；不稳时先放回并重新对齐和抓取，稳定后再搬运。
6. **抬升与搬运恢复**：覆盖抬升过高、横向偏离、搬运不到位的状态，保持稳定夹持并到达蓝盒上方。
7. **下降、放置、释放与撤离**：覆盖盒上不下降/不松爪、盒外或高处提前松爪的前兆状态；完成对中、下降、释放、撤离与盒内稳定验证。

先优先采集第1～4类，再扩展第5～7类。条数不得把同一失败的多个现象重复当作独立失败率；最新仅杯子30次与更早多物体30次分开统计。

## 纠偏采集方式与验收

- 优先从策略真实访问的可恢复失败状态接管，保存来源模型、评估回合、种子、时间、杯子和机器人位姿、原始偏差、接管点、专家恢复动作及后续结果。合成扰动课程单独标明来源。
- 覆盖多格位置、不同接近方向和物体位移；大偏差不得只用毫米级参考位扰动替代。
- 录制恢复到完整任务结束：恢复→闭爪→稳定离桌→搬运→下降入盒→释放→撤离。片段可以单独标注供采样，但不得将只完成试抬标成完整放置成功。
- 同步记录三路RGB、实际关节状态、执行动作、物体/接触状态、阶段及任务prompt。动作标签按真实指令生成，保留开→闭→开，释放之后保留至少16帧真实尾部观测。
- 统一−90°抓取分支，闭爪前FK滚转验收为−90°±3°；保持生产碰撞、稳定夹持、离桌、盒内放置和释放判据。
- 接近和正式录制期间杯子保持动态、碰撞开启；不通过冻结、附着或瞬移完成纠偏。准备阶段如有冻结或重置，必须在运动前解除并确认。
- 失败尝试可保存诊断日志，不计入成功配额；异常夹持、真实碰桌、图像缺失、同步或标签不完整不得收入成功示范。
- 训练与验证按独立网格/布局划分；原保留验证格为(column,row)=(1,1)、(2,3)。设计纠偏使用的评估种子不再充当独立测试集。

## 渲染与数据版本

- 使用杯子及桌面透明物体修复后的RTX设置：`/rtx/translucency/worldEps=0.0001`，首帧渲染初始化后再次应用。该值是折射近似阈值，不是材质IOR。
- 正式录制前抽查腕部和两个外部视角遮挡。保留真实材质，不以强制不透明替代修复。
- 已训练ACT所用236条来源记录均早于修复，抽查发现基础与两类纠偏均存在伪影；未逐帧证明所有记录均受影响。旧基础与旧纠偏不能未经复核混入新的正常渲染版本。
- 重新导出或重建训练缓存，记录数据来源；不把修复评估渲染视为修复旧JPG或旧模型。

## 本轮基础集

- 4行×5列（column=0..4，row=0..3），每格20条完整成功示范，目标400条。
- 先录基础示范，本轮不训练模型、不录纠偏。
- 使用新目录；成功数只来自本轮新录制并验收的数据，不用旧160条或旧纠偏填充配额。
- 使用三相机、10Hz录制、动态抓取与完整入盒释放流程；−90°分支，渲染阈值0.0001。
- 保留通用多物体桌面场景的其他物体布局，目标固定cup；本轮未要求将其他物体从场景删除。
- 每格在同一原网格范围内采不同随机布局/种子；不把20条同轨迹复制当作20条示范。失败不计数，已验收记录支持断点续录。
