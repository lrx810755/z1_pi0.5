## 1. 本次目标

修正苹果在真实物理抓取完成前主动跟随 `GRIPPERMOVER` 的问题，确保流程严格遵守：

```text
动态物体 + 完整重力
→ 低速闭爪
→ 持续双指接触
→ 无 ATTACH 物理抬升
→ 连续证据验收
→ 才允许 ATTACH
→ 搬运和放置
```

抓取成功不能由 `ATTACH`、运动学冻结、关闭重力或直接改写物体位姿产生。

## 2. 问题复核

复核已保存的 `episode_000002` 后确认：

- 物理试抬阶段没有建立运输约束；

辅助验证数据。

## 3. 已实施修改

### 3.1 取消试抬重力补偿

抓取助手不再发送：

- `gravity_compensate`
- `GRAVITY_COMPENSATED`
- 试抬结束后的配套 `gravity_restore`

苹果从闭爪、抬升到物理验证完成始终承受完整重力。

### 3.2 连续验证真实物理夹取

试抬顶部改为连续 5 个样本验收，采样间隔 0.10 秒。每个样本必须同时满足：

- `attached=false`
- `transport_constraint_active=false`
- `physics_enabled=true`
- `gravity_enabled=true`
- PhysX 接触报告可用
- 左右夹指持续接触同一个苹果
- 夹指均未接触桌面
- 苹果未接触桌面
- 苹果几何中心位于严格夹持包络内
- 苹果实际上升不少于 25 mm
- 苹果与夹爪的相对跟随误差不超过 25 mm

任意一个样本失败都会拒绝抓取，不会授权 `ATTACH`。

### 3.3 场景端增加不可绕过的 ATTACH 门禁

Isaac 场景新增 `_physical_grasp_evidence()`，由场景自身读取物理状态。

场景在以下两个时刻分别重新核验：

1. 接收 `physical_grasp_verified` 时；
2. 真正执行 `ATTACH` 前。

核验内容包括完整重力、动态状态、碰撞恢复、持续双指接触、夹指不碰桌、苹果离桌、
严格夹持包络和最小实际抬升。证据失效时会清除授权并拒绝绑定，因此客户端不能仅靠
发送布尔命令提前吸附苹果。

### 3.4 配置与测试

物理试抬配置新增：

```json
"verification_samples_required": 5,
"verification_poll_period_s": 0.10
```

新增测试确认连续带载验证参数不能被意外取消。
