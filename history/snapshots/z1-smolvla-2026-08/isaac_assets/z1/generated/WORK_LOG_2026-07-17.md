Isaac Camera 在 ROS optical frame 下额外旋转 `(180°, 0°, 0°)`。这是坐标约定转换：

```text
ROS optical：+Z 向前，+X 向右，+Y 向下
Isaac Camera：-Z 向前，+X 向右，+Y 向上
```

该旋转不会改变 URDF 中的物理安装外参。

## 9. 构建过程中的问题及处理

### 9.1 `package://` mesh 无法解析

Isaac Sim 5.1 的 headless URDF Importer 没有自动解析：

```text
package://z1_description/...
```

构建脚本会生成：

`z1_with_d435_resolved.urdf`

其中 mesh URI 被替换为实际的绝对路径。重新构建时必须保留这一步，否则生成的机器人会缺少外观 mesh。

### 9.2 固定关节不能合并

导入参数必须为：

```text
merge_fixed_joints = False
```

否则以下 frame 可能消失：

```text
gripperStator
camera_link
camera_color_optical_frame
camera_depth_optical_frame
```

### 9.3 Isaac Importer 空 visual 引用

Isaac Sim 5.1 会为空 TF link 创建无效 visual reference，导致大量：

```text
Unresolved reference prim path
```

构建脚本会从 importer 的 base layer 中删除这些空 visual reference。生成完成后的场景重新打开时已验证不存在未解析引用。

### 9.4 相机近场遮挡

腕部相机预览顶部存在少量黑色机械结构。这来自 D435/夹爪真实安装链附近的模型，不是错误生成的红色遮挡物。

后续需要结合实际真机画面判断：

- 是否属于真实视场内结构；
- 是否需要细调 D435 安装位置；
- 是否需要对训练图像进行固定裁剪。

不要在没有和真机视场对比前直接删除该结构。
