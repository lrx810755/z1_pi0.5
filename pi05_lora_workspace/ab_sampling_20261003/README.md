# 瓶子 π0.5 LoRA 采样对照训练

## 问题与设计

检验降低闭爪前静止等待片段的采样概率、提高腕部运动和闭爪过渡片段的采样概率，是否改善闭爪延迟。此次不裁剪任何中间帧、不改动作标签、不改模型输入，也不改变每个样本内部的连续 50 帧动作窗口。源数据沿用此前只处理首尾重复帧的版本。

两组都使用有放回采样，以免采样算法本身成为额外变量；A 的所有帧权重为 1，B 使用下表。所有帧权重均大于 0。阶段是根据关节运动和夹爪指令划分的启发式标签，不代表已经识别到视觉遮挡或成功抓取。

| 阶段 | B 权重 | A 预期采样占比 | B 预期采样占比 |
|---|---:|---:|---:|
| 张爪静止等待 | 0.25 | 15.80% | 3.21% |
| 闭爪前腕部运动 | 2 | 26.84% | 43.58% |
| 首次闭爪前后过渡 | 3 | 4.11% | 10.00% |
| 其余 | 1 | 53.25% | 43.22% |

等待：首次闭爪之前，局部最多 5 帧内全部六个关节的范围不超过 0.01 rad，且夹爪指令小于 -0.85。腕部运动：其余闭爪前样本中，局部腕部三个关节至少一个范围达到 0.02 rad。首次闭爪：夹爪指令首次达到 -0.75；前 5 帧至后 5 帧优先标为闭爪过渡。这里的等待包含开头等待，因此占比不等于此前仅统计末段等待的约 11%。

## 两组共同设置

- 初始化：`/home/lp531/smolvla_training/pi05_bottle_lora_20261001/checkpoints/108000/pretrained_model`，每组加载后逐张量验证一致。
- 使用相同的新 AdamW 优化器；不继承旧训练优化器状态。
- LoRA rank=32，alpha=32；沿用原目标层和全量训练的动作投影层，8,358,944 个可训练参数。
- microbatch=2，梯度累积=4，有效 batch=8。
- 每组 12,000 个 microsteps，即 3,000 次优化器更新。
- 学习率预热 200 次更新至 3e-5，随后余弦下降至 1e-5。
- 每 500 次更新保存；每 1,000 次更新在同一组 25 条验证轨迹上计算离线损失。
- seed=20261003；BF16，梯度检查点，视觉编码器冻结。
- 原始数据共 246 条、65,773 帧；固定划分 221 条训练 / 25 条验证。
- 预处理已逐帧核对训练数据的 state/action 与原始准备数据完全一致，保留源轨迹顺序。
- A/B 配置已自动核对：除输出目录和作业名外完全一致。采样权重在训练入口单独注入。

## 运行与产物

后台单元：`pi05-bottle-sampling-ab-20261003.service`。依次执行 A（uniform）和 B（weighted），避免同时占用显存。停止后不会自动覆盖已有输出或日志；需要检查中断原因后再恢复。

```bash
systemctl --user status pi05-bottle-sampling-ab-20261003.service
tail -n 25 /home/lp531/pi05_lora_workspace/ab_sampling_20261003/uniform.log
tail -n 25 /home/lp531/pi05_lora_workspace/ab_sampling_20261003/weighted.log
```

输出目录：`/home/lp531/smolvla_training/pi05_bottle_sampling_ab_20261003/{uniform,weighted}`。

本目录保存输入哈希、逐轨迹权重统计、配置、初始化检查结果、日志及完成标记。两组完成后生成 `comparison_summary.json`。`smoke_weighted` 是独立的单次优化器更新预检，不作为正式训练初始化。

## 如何比较

这是单个配对随机种子的初步实验。离线损失用于检查训练是否正常，不能直接证明撞瓶改善。完成后应使用两组相同训练步数的检查点、相同瓶子位置和随机种子、相同冻结及控制配置，比较首次闭爪时机、触瓶前是否闭爪、撞倒率、抬起成功率和完整任务成功率。原始 108000 检查点也应保留作基线。

此次任务仅启动训练；没有自动运行机器人或仿真动作评估。阶段加权能否改善可观测性不足和动作时序，需要上述评估验证。
