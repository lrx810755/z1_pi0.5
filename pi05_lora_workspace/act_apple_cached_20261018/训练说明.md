# 苹果 ACT：基础示范＋纠偏片段（2026-10-18）

已停止纠偏采集，冻结133条完整入盒示范和59条有效纠偏片段，共192条、47335帧。

- 原始输入：三路JPEG画面、六关节及实际夹爪角度，10Hz。
- 预解码：从JPEG直接解码，按原ACT部署流程补黑边成640×640后缩放224×224，保存float32 RGB [0,1] 内存映射缓存；训练batch不再解码JPEG/视频。部署预处理仍从原分辨率接收图像。
- 数据读取：本目录cache_data.py的Torch Dataset适配器读取冻结数据和缓存，训练仍使用已有LeRobot ACT训练器。缓存目录不是可直接交给通用LeRobot CLI的视频数据集，请使用本目录run_training.sh。
- 动作：六关节连续目标＋夹爪二值意图；观测夹爪仍为真实连续角度。
- 基础集闭爪标签：用实际闭爪指令坡段回溯到首个>-0.895命令，不依赖GRASPING阶段；忽略准备时短暂角度保持后重新开爪的扰动。放置阶段最终开爪坡段标为0。
- 纠偏标签：沿用验收后的0/1标签；episode_000043保存过程多录了最后1帧，确认其指令仍为闭爪后，在训练副本中补上末帧标签，不改原始数据。
- 训练170条、验证22条：两来源统一预留网格(1,1)、(2,3)，无训练/验证格重叠。归一化统计仅由训练集计算，图像使用ImageNet统计。
- 采样：基础70%、纠偏30%；闭爪前2秒至闭爪首帧，以及纠偏恢复段，池内2倍，其余1倍。包含闭爪首帧；并非上次细阶段大幅加权配置。
- 每个锚点后16个动作必须完全位于本episode内；不跨集、不跨片段拼接，不将纠偏片段伪造为完整入盒。
- 模型：ACT，ResNet18 ImageNet初始化视觉骨干，其余ACT参数从头初始化；不续训瓶子模型。
- batch=16，梯度累积=1，50000次优化器更新，chunk_size=16，AdamW，模型/骨干学习率均1e-5，weight_decay=1e-4，KL=10，float32。
- 不使用图像增强；每5000步验证/保存，另在第20步保存首个验证训练已启动的checkpoint。n_action_steps=5是模型默认部署配置，实际评估执行步数后续可单独指定。

启动链路：缓存生成 → 缓存与原图/动作一致性验证 → 4步试训 → checkpoint重新加载及真实原图推理验证 → 正式50000步训练。
