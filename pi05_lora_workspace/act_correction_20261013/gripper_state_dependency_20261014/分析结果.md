# ACT 固定观测夹爪状态对照

模型ACT 050000。21条验证示范闭爪起点，以及两次失败评估各3组接近到位时的观测，共27组；每组保留三路RGB和六个机械臂关节值，只修改observation.state最后一维实际夹爪角度。每组9个输入（原状态+8个对照角度），共243次16步动作预测。模型eval模式，无机器人命令。

## 结果

验证示范21组：角度-0.9/-0.895/-0.88/-0.85/-0.8时，首步超过0.6均为10/21；-0.75和-0.7时为12/21；0rad时为21/21。正常范围内变化未使触发能力显著改善。前8步包含闭爪的比例正常角度均为20/21，0rad为21/21。

失败评估6组：-0.9至-0.7rad的首步及前8步均无闭爪。原张开状态首步约0.009至0.014；-0.7rad时升至0.234至0.383，仍低于0.6；0rad时全部变为0.965至1.006并立即预测闭合。

seed437216237的query16、17，在张开状态下预测中的闭爪首次出现在零基下标14、12，也就是第15、13个动作。实际评估每次执行前8步，因此这两次未执行到计划中的闭爪。单次预测的未来闭合并不保证不断重新规划时最终触发。

## 判断

模型输出受实际夹爪状态影响，这是干预下观察到的敏感性。正常示范范围内稍微改变夹爪角度没有解决闭爪启动；0rad输入的变化不足以证明模型主要依靠状态shortcut。瓶子夹持示范的实际角度通常约-0.7rad，假设0rad完全闭合可能离开该局部数据分布，且与固定的张开画面矛盾。因此不能据此直接决定改训练。

本实验更支持继续定位接近视觉/姿态分布与未来闭合时机：验证示范可以在前8步安排闭爪，失败观测却可能将闭爪放在更远的未来。不能据此声称已经证明由执行8步引起失败，也不建议直接增大执行步数而跳过闭环对照。

## 数据限制

验证示范使用准确配对的观测。失败评估未保存送入网络的原始图像tensor，使用查询前录像快照及input_sync.jsonl记录的同步关节输入，按视频写入顺序重建；MP4有损且查询快照与同步选取图像可能略有差异。原状态回放与当时首步预测最大绝对误差为0.00031239，说明首步数值重现接近，但不能证明图像完全一致。

没有重跑自主闭环任务、没有改变实际夹爪、没有发送控制命令。这是失败自主评估观测的离线反事实推理，不能用作成功率结果。
