# 精细阶段采样 ACT 对照实验

用户授权从头训练新ACT，采用此前精细阶段权重。与温和ACT基线共享数据、划分、归一化、图像缓存和优化器配置。

- 输出：/home/lp531/smolvla_training/act_fine_cached_chunk16_20261015
- 模型：完整ACT，ImageNet ResNet18骨干初始化；不从旧ACT checkpoint续训。
- 50000次优化器更新，batch16，梯度累积1，seed20261013。
- AdamW：主体/骨干学习率1e-5，weight decay1e-4，梯度裁剪1；float32。
- chunk16，7维实际关节状态，7维动作（二值夹爪标签），三相机。
- 数据211条，190训练/21验证，35662个完整合法训练窗口。split/train_stats逐字节与温和基线一致。
- 原始/纠偏来源采样概率70%/30%。闭爪前1秒1.5，闭爪2，准备抬升2，初始抬升1.5，稳定持握/其他1。已记录纠偏恢复区间至少2，重叠取最大，不相乘。
- 全部190个训练首次闭爪帧已验证处于closing且权重2。动作loss仍统一1。
- 复用act_rgb224_float32_cache_20261015的633个缓存文件，4个spawn数据worker；不重建缓存，训练不读取视频解码器。部署checkpoint保留原始图像裁剪缩放处理器。
- 先做4次更新短训练及三种来源真实验证观测的保存/重载检查，再独立从头启动50k主训练。
- 首个正式checkpoint在20步，其后每5000步保存；最终050000。

实际各阶段采样概率见sampling_audit.json。该实验改变完整精细阶段采样方案，不能仅归因于首次闭爪帧的变化。未启动模型评估。
