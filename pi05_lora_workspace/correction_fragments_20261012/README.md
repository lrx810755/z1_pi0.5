夹爪动作标签在首次闭爪命令开始前为0，之后为1，保留真实关节状态及其余6维动作。片段末尾14个训练锚点排除，避免15步动作块越界。4条新验证片段整条排除训练；加上既有4条验证，合并后预计212条：204训练、8验证。旧数据动作/状态逐值核验，归一化统计沿用旧数据。
