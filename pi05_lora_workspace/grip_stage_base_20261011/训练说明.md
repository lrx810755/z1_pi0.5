- 从 `/home/lp531/pi05_lora_workspace/weights/pi05_base` 重新加载，生成全新 LoRA；不加载旧 adapter，不恢复旧优化器。

- 原始/补录训练采样质量分别为 70%/30%，各池分别归一化。

- 120000 微步，microbatch=1，单卡，梯度累积 8，有效 batch=8，共 15000 次优化器更新。

- LoRA r=32、alpha=32；语言主干与动作专家所有层的 q/k/v/o、gate/up/down；动作输入/输出及时间 MLP 投影完整训练，视觉编码器冻结。与上一版范围相同。
