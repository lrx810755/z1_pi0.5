如以后明确调整来源，需要先重新整理、转换：

```bash

```

- 整理：读取 data_sources.json，要求原172条、追加41条及杯子7条队列完成审计，并核对新增瓶子25条的用户关闭子集审计；递归应用旧→新替换表，以真实路径和 frames SHA256 去重；保存 sources_frozen.json。
- 转换：复核冻结输入；复查反向移动8cm阈值，按精确路径和内容哈希保留你明确接受的4条；读取 frames.jsonl、episode_start/summary、纠偏元数据及标签/掩码；逐张解码并固定三路JPEG校验值，已有解码缓存经过文件状态或内容校验后复用；生成 lowdim.npz、sampling_arrays.npz、image_pins.npz、split_manifest.json 和 train_stats.json。CPU验证包含归一化往返、预处理器保存与加载。采用此前已用过的原生LeRobot自定义Dataset接口，无需MP4或额外Parquet。
- 训练：只有执行第三条命令才会调用GPU。先进行8微步/1次参数更新的独立冒烟训练，再重新加载检查模型，最后从官方底座重新初始化正式LoRA。冒烟权重不会作为正式训练初始权重。GPU检查尚未在本轮执行；失败会停止，不覆盖已有输出。

全部选定示范用于训练，无验证集。苹果/桃子纠偏保留原完整任务文本。H=30要求从锚点开始连续30帧均为专家动作；片段末29帧不能当锚点，但可以作为前面窗口的动作目标。干预区间排除，不跨集、不伪造后续动作，不直接删除原始尾帧。

状态保留实际7维关节角；动作保留六轴命令，夹爪转为0/1命令意图。旧杯子沿用上一轮已固定的标签；其余基础示范按上一轮已验证的闭合/松开命令斜坡规则生成意图标签，相较先前阈值推导，1255条中的23725帧发生修正。纠偏沿用保存标签，并核对显式命令事件。早期苹果片段保留其已保存标签；苹果 episode_000055 的单个缺失末帧标签，仅在派生数组中根据已有事件补齐。额外排除9帧仍携带干预期间命令的边界帧。所有修正均未改动原始示范文件。

归一化在最终数据确定后计算，统计所有进入有效专家窗口的帧，保存共享state/action的q01/q99，训练时固定。RGB保持比例补边成正方形，再缩放224×224；部署预处理同步保存。

参数：10Hz、chunk30、执行15；LoRA rank/alpha32、dropout0、冻结视觉、BF16、梯度检查点；microbatch2（不同物体）×累积8=16窗口/参数更新。每次参数更新每种物体恰好3基础+1纠偏。池内普通权重1，夹爪变化±8帧1.5，恢复区间3，重叠取最大；每次更新内不重复同一锚点。100000次参数更新，对应800000微步；warmup2500次更新，学习率2.5e-5降至2.5e-6，每5000次更新保存。采样仅支持单GPU。

输出：`/home/lp531/smolvla_training/pi05_current_round_20261111`。这是新训练入口，不提供旧训练断点继续命令；拒绝覆盖已有输出。重新转换后旧冒烟通过标记不能授权新数据训练。
