# PI0.5 四轨迹小数据微调

本实验检查现有 PI0.5 微调流程能否学会少量已见场景。回放用于筛选数据，不计入模型自主成功。

## 数据

- 使用现有二值夹爪数据集的原生 episodes 过滤器，只读取 episode index `[74,82,99,110]`。
- 对应原始轨迹：000157、000160、000154、000155，共 **858 帧**，10 Hz、三相机。
- 均位于 5×5 网格的 `[4,3]` 区域，瓶子初始位置最大相距约 7.1 cm。
- 保留四条完整轨迹，未裁剪开头、中间或末尾，原始数据集没有修改。
- 验证集为 0 条，这是训练集拟合诊断。归一化沿用原 160 条数据的统计，避免同时改变输入输出尺度。

筛选中检查了 11 条候选的物理回放。最终四条均通过当前回放判据，并要求瓶子参考点在箱内、距离内壁有保守余量、参考点高度接近箱底 0.01 m。已保存两路外部视角末帧。这个位置检查不是完整视觉网格包含关系的证明，仍不能用它代替后续严格的全自主入箱验收。

## 训练配置

| 参数 | 值 |
|---|---|
| 初始化 | 官方 pi05_base，从头建立新的 LoRA；不续训之前的 080000 |
| Chunk size | 15 |
| LoRA | language + action expert 的 q/k/v/o attention 和 gate/up/down FFN |
| Rank / alpha | 32 / 32 |
| 全量训练投影 | action_in/out、time_mlp_in/out |
| 视觉编码器 | 冻结 |
| 动作 | 前六维绝对关节角；夹爪动作 0 开/1 闭；夹爪状态为连续实际角度 |
| 微批 / 梯度累积 / 有效 batch | 1 / 8 / 8 |
| 优化器更新次数 | 1,000 |
| 日志中的 microsteps | 8,000 |
| checkpoint | 2,000 / 4,000 / 6,000 / 8,000 microsteps，对应 250 / 500 / 750 / 1,000 次更新 |
| 峰值学习率 | 5e-5 |
| 实际学习率日程 | 框架按短训练自动压缩日程：50 次更新 warmup，1,000 次更新内衰减到 5e-6 |
| 精度 | bf16 + gradient checkpointing |
| 图像增强 | 关闭，与上一轮相同 |
| seed | 20261007 |

启动日志确认：原配置的 4,000/80,000 microstep warmup/decay 被原生 scheduler 自动缩放为 400/8,000 microsteps。因此实际 warmup 是 50 次更新。峰值/末端学习率不变，但时间日程随训练预算缩短；本实验检查小数据能否学会，不是严格隔离“只改变数据条数”的因果对照。

## 验证与后续判据

实际 LeRobot 加载器已验证只包含指定 4 条、858 帧；每条 frame_index 连续且完整；实际抽取了 15×7 动作和三相机图像。未更改日常验证的执行频率、限位或夹爪控制。

训练完成后需检查初始/接近/闭爪/搬运/释放阶段的原始预测，并从这些场景的初始状态进行模型全程自主测试；少量场景通过也只说明记忆/拟合能力，不能声称完成泛化复现。
