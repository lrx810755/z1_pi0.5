# 独立杯子连续接近录制 V2

预览：`bash /home/lp531/SH/start_cup_horizontal_demo.sh --dry-run`
启动：`bash /home/lp531/SH/start_cup_horizontal_demo.sh`
状态：`bash /home/lp531/SH/start_cup_horizontal_demo.sh --status`

有头模式，只运行该入口的一个Sim。默认20格×每格1条完整成功抓放、10Hz三相机。数据：`/home/lp531/smolvla_data/cup_horizontal_v2_demo_20261105`；日志：`/home/lp531/z1_queue_logs/cup_horizontal_v2_demo_20261105`。原两段版4条数据和日志保留。源码上一版备份在backup_two_segment。

三段：当前位→外侧高位PTP→外侧低位LIN→最终位LIN。高位/低位都是连续通过点，各3mm融合，整段必须只有一条轨迹，单次arm action发送。外侧高位与低位采用最终抓取姿态，第一段完成转姿；高位到低位在目标外侧下降。最终位允许停止作精确验收后闭爪；这不是保证完整搬运放置任务没有其他验收等待。

候选通道18条：低位沿夹爪插入轴的水平投影反向退让60/80/100mm；高位较低位高80/120mm；高位可再沿水平横向偏移，偏移量=退让距离×tan(0/±15度)。方位变化只改变外侧下降通道，低位点保持最终插入轴线，末段仍水平。前两段速度缩放0.08，最后一段0.064，即原低速的0.8倍。

新代码只复用原杯子的标定目标生成公式与物理闭爪/搬运/释放支持，不再要求旧接近路径先规划成功。不同最终抓取位候选与外侧通道交错尝试，选择首个通过完整规划、FK与连续性验收的组合。低位穷举不受统一90秒预算截断；单个候选等待上限为段数×planning_time＋15秒，高位阶段独立限时90秒。规划服务超时时本地future取消，服务端取消能力有限，但没有轨迹执行副作用。

保持：夹指插值几何离桌>=3mm；末段高度偏差<=2mm、横向走廊<=2mm、姿态偏差<=0.035rad；目标工具轴俯仰绝对值<=7度；内部关节速度不得全零；计划失效/起始臂位移动/杯位移动后拒绝执行。不放宽碰撞、不关闭物体碰撞、不用静态杯子伪造成功。使用原完整物理抓放验收。

运行前等待录制、复位、碰撞场景、物体碰撞及Sim连接全部就绪，录制器参数发现有重试。独立MoveIt默认Pilz管线，显式关节加减速限值1/-1rad/s²（只作用本入口）；原冻结支持内非线性规划显式选择OMPL。ROS_DOMAIN_ID=129，任务GUI端口8832。GPU显存不足时拒绝启动。
