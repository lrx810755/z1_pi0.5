# 杯子：独立连续水平接近示范入口

先核对：`bash /home/lp531/SH/start_cup_horizontal_demo.sh --dry-run`
开始采集：`bash /home/lp531/SH/start_cup_horizontal_demo.sh`
查看计数：`bash /home/lp531/SH/start_cup_horizontal_demo.sh --status`

本版仅支持杯子，默认20格×每格1条完整成功抓放，共20条小批样本；10Hz、左腕+两个外部相机。新数据 `/home/lp531/smolvla_data/cup_horizontal_demo_20261105`；日志/规划证据 `/home/lp531/z1_queue_logs/cup_horizontal_demo_20261105`；域129。GPU空闲显存不足18000MiB时退出，不能与当前LoRA训练同时运行。

独立assistant.py替换接近逻辑：使用冻结的基类副本提供杯子的既有标定目标、闭爪、物理试抬、搬运、放置和成功验收，旧接近规划只用于生成标定目标且被丢弃，不执行。生产抓取源码、原启动脚本和旧数据均未修改。本版不等于所有依赖完全独立，仍使用ROS消息、MoveIt配置、轨迹桥、GUI/录制器等公用组件。

新接近：先整体规划PTP外侧点与LIN最终位，两者用Pilz序列3mm融合，必须只返回一条轨迹，只发送一次机械臂执行action。外侧点相对最终位水平退让60mm，保持最终高度/姿态；进入近目标区之前完成转姿与下降。末段保持近水平轴向（目标轴俯仰绝对值<=7度，沿用杯子约-5度标定）、高度误差<=2mm、方向偏差<=约2度、横向走廊<=2mm，夹指完整插值路径最低点>=3mm。融合区是圆滑通过区，不要求精确命中中间点。

外侧速度缩放0.08；末段速度缩放0.08×0.8=0.064。用户确认倍率含义。这不是0.8m/s，也不更改闭爪速度。原脚本接近两段都是0.08，并非原来只有末段低速。带载搬运原配置0.08/加速度0.04；物理试抬0.12；放置中未显式给速度的动作读取通用speed_scale，默认0.35。本版仅替换开爪接近轨迹，不统一修改这些阶段。

连续性要求适用于两段连接处：不插入运行时规划/中途等待，不允许内部关节速度全零或退回普通停点拼接。最终到位后保留物理位置/姿态/接触验收，再闭爪；不保证整个完整抓放任务没有规划或验收等待。实际控制误差仍可能导致停止。

失败时拒收：序列服务不可用、返回多条停点轨迹、空速度/内部停车、时序不单调、FK/离桌/水平走廊不满足、规划后杯位移动>3mm、起始关节变化>0.01rad，或复位/停止/目标切换使旧计划失效。禁止冻结物体来掩盖接近碰撞，目标在接近前保持动态物理，碰撞与原完整成功验收保留。

已完成5项纯规则测试（包括中途停车拒绝/时序错误拒绝）、ROS导入与服务类型检查、实际URDF/STL几何初始化、旧计划失效拒绝测试、Bash语法及dry-run，独立复核无剩余阻断问题。未启动仿真、未采集示范、未验证实际规划可解性与物理撞飞改善；第一次运行仍需核对规划与执行证据，不能将CPU检查说成实际连续运动已经验证。

显示模式：独立入口现为headless:=false，直接显示本次录制的Isaac窗口，无需另开Sim。
