# 所有训练集轨迹筛查与2倍速汇总视频

运行：`bash /home/lp531/SH/start_dataset_trajectory_review_20261111.sh`

默认仅扫描`current_round_sources.json`列出的本轮8个新录制目录，排除历史和预处理版本。正在进行的替换重录另计，完成后再按来源替换关系更新范围。忽略`.recording_*`、图像子目录和诊断目录，不自动读取既有MP4，不加载模型，不启动或停止仿真，不修改原始数据。

脚本`review.py`可通过`--roots`指定任意数据集目录、多个目录或frames.jsonl文件，通过`--output`指定新输出目录。`--no-video`仅生成清单；`--thresholds`读取自定义JSON阈值。默认阈值会保存到输出目录。

默认筛查连续3秒以上低进展停顿（5秒列为高优先级）、4秒以上尾部停留、同一数据集/物体/任务类别的总时间和阶段时间离群、累计明显反向移动、局部往返抖动、绕行、时间采样间断、帧数和数值错误。方向、抖动采用Z1 URDF关节FK；无URDF时明确降级为关节与时间检查。时间和视频适配10Hz、20Hz等记录频率。

已标注人为扰动的帧排除出运动异常和同类时长比较。夹爪动作单独判断，防止将正常闭爪当作机械臂停顿。必要的恢复、避障和验收等待仍可能命中规则，因此结果均为人工复核候选，不自动决定删除或重录。

输出：

- `异常候选清单.csv`：与视频同序编号，数据集、episode、异常区间和依据、视频起止时间，并留有人工结论、是否重录和备注空列。UTF-8 BOM，方便表格软件打开。
- `异常轨迹汇总_2倍速.mp4`：所有候选episode完整回合，按清单顺序拼接；每条片头0.8秒，运动轨迹2倍速，最多三视角，标注当前时间和异常区间。可按章节跳转。
- `所有样本指标.csv`、`数据集覆盖.csv`、`无法分析.csv`、`图像读取问题.csv`：完整覆盖与错误记录。
- `candidate_manifest.json`、`all_metrics.json`、`input_snapshot.json`、`thresholds.json`：可复现的来源、指标、阈值和明细。
- `status.json`、`run.log`、`ffmpeg.log`：进度和错误；只有整个视频完成并核对时长后才写`completed.json`。

视频按记录fps和原始帧序列播放为2倍速，不为采样间断补造动作。历史预处理引起的simulation_time跳跃会单列候选。图像缺失时显示警示占位并记录；整个frames无法解析时只能显示该条片头，错误仍保留在清单，不静默漏掉。

仅将指向同一物理文件的路径别名合并，其他历史/预处理版本分别列出。扫描快照在启动时固定，运行期间新保存的数据不会混入本轮；需要时可使用新输出目录重跑。

编码使用CPU和两个线程，降低优先级运行，不占用仿真CUDA显存。入口后台启动后返回，不进行自动监控或消息通知。
