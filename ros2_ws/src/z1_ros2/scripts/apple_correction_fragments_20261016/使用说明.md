# 苹果纠偏短片段采集

本脚本继承瓶子片段采集的流程：固定任务计划、完整预检、先准备偏差再录制、纠正后真实夹取离桌、成功落盘才占配额、按任务ID续采。没有使用瓶子的抓取高度、圆柱接触标准或±18毫米高度扰动。独立子类不修改正常采集节点。

## 命令

查看计划，不启动ROS或仿真：

```sh
bash /home/lp531/start_apple_correction_collection.sh --dry-run
```

一条命令启动仿真、三相机与采集，持续补齐60条成功片段：

```sh
bash /home/lp531/start_apple_correction_collection.sh --until-complete
```

有限尝试：默认三轮，最多180次尝试。每轮每个缺失任务尝试一次，已完成任务自动跳过。

```sh
bash /home/lp531/start_apple_correction_collection.sh
```

首次验证建议先尝试一条左右纠偏任务；本命令不会自动扩大到全计划：

```sh
bash /home/lp531/start_apple_correction_collection.sh --only left --per-kind-limit 1 --rounds 1
```

```sh
bash /home/lp531/start_apple_correction_collection.sh --status
```

可用 --headless 隐藏仿真窗口，--output 指定独立目录，--port 指定GUI端口。默认ROS_DOMAIN_ID=83、端口8773；与正在进行的普通苹果采集隔离，但两个Isaac实例仍会共享GPU资源。本次仅编写与静态验证，没有启动纠偏采集。

## 60条配额

|类型|数量|定义|
|---|---:|---|
|left/right|各8|沿基座到苹果的水平径向的左/右偏5、10mm|
|far|8|沿基座到苹果的水平径向偏远7、14mm|
|near|4|沿基座到苹果的水平径向偏近2、4mm|
|low/high|各4|世界Z偏低/高2、4mm|
|pitch_tilt|8|工具局部Y旋转±3、±5度|
|roll_tilt|4|工具局部X旋转±3、±5度|
|left_tilt/right_tilt|各4|小幅左右偏与工具局部X倾斜组合|
|close_ready|4|无人工偏差，直接记录已到位、张爪至开始闭合|

幅度为根据苹果低矮形状、当前接触/边缘采集问题选取的保守起点，并不是从苹果自主模型失败日志统计得出的量。尚需实际试录验证可达率。任务不把已倒落、闭爪后滑落等状态当作正常闭爪前纠偏。

苹果参考位置和姿态由当前苹果规划器得到，末端参考取真实计划终点的FK；沿用苹果原有接近倾角、抓取高度、夹持包络及物理夹持检查。普通脚本当前joint3 P=400000/D=1200，纠偏启动时会加载同一场景驱动配置。

20个有效网格为列0～3、行0～4，每格分配3条不同任务，共60条。不是把所有类别集中在同一个位置。两格(1,1)、(2,3)的全部6条预留validation，其余54条train；未来与原训练集合并时还要统一划分，不能直接假定这两个格在原训练集中也是验证集。

除close_ready外，准备阶段先沿基座到苹果的水平径向退14或20mm，在安全高位施加偏移和倾斜，然后下降到偏离状态。真正录制的是该状态后的恢复过程。恢复先提高必要净空，再纠正姿态、在上方对准、返回苹果参考抓取位。上下扰动始终是2～4mm；恢复安全走廊的18～25mm抬高是避碰路径，不是把苹果高度偏差扩大到瓶子的量级。

## 几何与验收

- MoveIt对准备和恢复全路径检查碰撞；从当前xacro解析URDF做FK和指尖网格高度预检。最低3mm桌面净空只用于准备/恢复路径的碰撞保护，不是已取消的物体目标6mm跟踪判据。
- 幅度不安全或路径不通就保留失败原因，换布局重试，不偷偷缩小扰动或用普通示范冒充。
- 准备时苹果保持重力和碰撞。若人工施加偏差期间把苹果推移超过5mm，该轮不计入配额；这是沿用瓶子逻辑的样本有效性检查，不是搬运跟踪检查。
- 不新增5/6mm末端跟踪失败门槛；沿用已有控制器运动保护和苹果自身夹取验收。
- 恢复完成后闭爪，原位连续试抬目标根节点Z=60mm，要求最终至少50mm、真实双指接触、动态物理和离桌，再保持2.2秒。片段不搬运、不放置、不伪造松爪标签。
- 片段成功与完整入盒成功区分：summary.fragment_success=true，episode_goal=apple_correction_grasp_lift；不人为写task_success=true。

## 录制与标签

输入为左腕、全局、右侧全局三路RGB，加六关节与实际夹爪角度，10Hz。准备人工偏差期间不录制；从偏离状态开始记录恢复、闭爪、抬升保持。

gripper_labels.json中，首个夹爪指令>-0.895rad为闭合首帧；不依赖可能包含整个对准过程的GRASPING阶段。此前0、此后1，恢复后再次开爪的片段不接收。这里是命令标签；原始observation.state仍保存连续实际角度，不被改成0/1。关闭首帧并不等于机械夹爪已完成闭合。

correction.json保存类型、网格、split、请求偏差、真实起点、恢复阶段时间、夹取保持结果与闭爪首帧。错误与当时真实位置保存在collection_logs内每次evidence_*.failure.json和attempts.jsonl中。

默认输出：/home/lp531/smolvla_data/z1_apple_correction_fragments_20261016。与普通苹果数据分开，不自动合并、不启动训练、不套用瓶子的LeRobot转换脚本。此脚本提供原始片段和标签，后续训练转换需显式选择对应完整16步动作窗口。

## 已完成的验证

- 8项纯逻辑测试：总配额、20格覆盖、上下幅度、格子级划分、低位先抬后旋转、闭爪标签、真实保持和错误物体不计配额。
- SH语法、Python编译、dry-run和ROS launch参数解析通过。
- 真实当前xacro解析和示范帧FK检查通过；参考帧指尖高度约15.2mm，工具局部±5度姿态的几何抽查有正净空。
- 尚未做实际苹果纠偏片段录制，不能声称60类任务都已物理可达或采集成功。

苹果接近接近竖直时，末端与苹果的水平差可能趋近零，因此左右/远近偏移使用“基座到苹果”的水平径向和切向定义，避免沿用瓶子近水平接近方向导致坐标不稳定。
