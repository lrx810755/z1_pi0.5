# PI0.5 纠正示范补录

一个终端执行：

```sh
bash /home/lp531/ros2_ws/src/z1_ros2/scripts/collect_pi05_corrections.sh
```

此命令自行启动 Isaac、MoveIt、三相机与录制器，按顺序尝试尚未完成的任务。一轮结束自动关闭本次启动的仿真。没有录满时打印续录 SH 命令；再次执行同一命令会读取磁盘成功记录并跳过已完成样本。

数据独立保存在 `/home/lp531/smolvla_data/z1_bottle_corrections_20261009`。原来的 160 条数据保持独立。默认一轮、最多 80 次尝试；失败不计入配额，不等于一次命令保证保存 80 条。可连续三轮：

```sh
bash /home/lp531/ros2_ws/src/z1_ros2/scripts/collect_pi05_corrections.sh --rounds 3 --max-attempts 240
```

查看进度（不启动仿真）：

```sh
bash /home/lp531/ros2_ws/src/z1_ros2/scripts/collect_pi05_corrections.sh --status
```

检查清单（不启动仿真）：

```sh
bash /home/lp531/ros2_ws/src/z1_ros2/scripts/collect_pi05_corrections.sh --dry-run
```

只补过低与倾斜：

```sh
bash /home/lp531/ros2_ws/src/z1_ros2/scripts/collect_pi05_corrections.sh --only tilt,low,low_tilt
```

## 数量、坐标与顺序

| 顺序 | 类型 | 成功配额 |
|---|---|---:|
| 1 | tilt：倾斜，工具局部 roll / pitch 正负方向 | 20 |
| 2 | low：过低 | 20 |
| 3 | low_tilt：过低叠加倾斜 | 16 |
| 4 | left：左偏 | 6 |
| 5 | right：右偏 | 6 |
| 6 | far：偏远 | 4 |
| 7 | near：偏近 | 4 |
| 8 | high：偏高 | 4 |

左右、远近以水平接近方向定义；上下使用世界竖直方向。工具姿态扰动通过四元数组合，不是单关节加角度。全部动作使用末端位置/方向约束交给 MoveIt 求解，再执行多关节轨迹。

`correction_plan.json` 保存幅度来源：12 条四示范模型失败轨迹、碰桌前或结束前 0.3 秒的状态、对应成功示范闭爪前位姿、差值和分位数。原始偏差受执行范围上限限制，并使用 65% / 100% 两档；当前约前后 13.3/20.5 mm、左右 19.5/30 mm、上下 11.7/18 mm、倾斜 9.2/14.2°。这是失败驱动的合成纠正状态，不是所有失败类别的原样复现；对称方向属于补充覆盖。

每类在原有 5×4 个已采集网格轮转。每次具体场景重新随机化并保存实际 seed 和物体位置。不可达、碰撞或抓放失败的任务保持待完成，下轮同任务使用新随机布局重试。

## 录制边界与质量

先执行正常预抓取，在未录制阶段抬高、退开并建立偏离状态。瓶子在录制前解除固定。录制从真实偏离状态开始，依次记录抬升留出间隙、恢复姿态、水平对齐、接近、原有物理抓取、搬运和释放。准备走偏的动作不加入训练标签。

沿用原录制器三路 RGB、7 维真实关节状态、7 维实际发送的绝对目标、10 Hz、同步容差 45 ms、固定网格采样与因果动作配对。原始夹爪动作仍为连续弧度，与原始 160 条录制格式一致；未来合并到 PI0.5 二值训练集时仍需按开闭意图转换，不要直接把原始弧度当 0/1。

纠正准备/恢复轨迹有 MoveIt 碰撞检查和采样间隔不超过 0.01 rad 的夹爪网格扫掠高度检查，最低间隙 6 mm；URDF 高度检查是近似，实际接触仍由 PhysX 判据验收。任何保存样本都需要恢复完成、多关节运动、无手指碰桌、原录制器完整抓放证据以及严格最终参考点范围。不会降低验收来填配额。

每个有效 `episode_XXXXXX` 包含原始图像/帧/摘要及 `correction.json`，记录任务编号、计划哈希、请求与实际偏离位姿、四段纠正的仿真时间、关节运动范围及最终验收。`collection_logs` 保留启动日志、逐次尝试和失败原因。临时 `.recording_*` 不计数，重启时移入日志目录隔离保留。

本脚本使用独立 ROS_DOMAIN_ID=81、HTTP 8769，避免与旧仿真时钟混合。`Ctrl+C` 或 TERM 会停止本次录制并回收本次启动的仿真进程；不要同时手工操作这个专用录制场景。没有训练或模型推理步骤。
