# 失败驱动纠正示范补录

目标：复用原三相机 10 Hz 录制、MoveIt 规划、物理抓取/放置流程，单个 SH 启停场景并断点续录。用户已授权实现和决定数量，直接实施。

独立扩展现有流程，原 160 条数据保持独立；新 launch 仅为本次运行替换助手、GUI 和录制器为子类。

80 条成功配额，按 tilt 20、low 20、low_tilt 16、left 6、right 6、far 4、near 4、high 4 顺序采集。倾斜与偏低合计 56 条。沿用原数据 20 个网格。幅度取失败状态与同场景示范闭爪前位姿差分位数，受可执行范围限制；保存原统计、幅度裁切、实际到达偏移。不是原样重放失败状态。

正常生成并执行预抓取后，在未录制阶段建立安全偏离位姿。录制从偏离状态开始：先抬升、恢复姿态、重新对齐、回到预抓取，再复用抓取、抬升、搬运和释放。使用笛卡尔位姿规划多关节轨迹。主动走偏的准备动作不进入训练帧。

验收：原录制器物理证据，加上无碰桌、严格最终参考点范围、实际偏移与多关节运动。保存 task_id 和计划哈希，恢复仅计有效已保存 episode；临时或失败文件不计数。失败继续后续任务，一轮结束打印相同 SH 续录命令。

实现任务：
- [x] core.py / geometry.py：清单、偏差统计、进度与几何检查，先写测试。
- [x] nodes.py：三个节点子类、录制边界和纠正元数据。
- [x] collection.launch.py / supervisor.py / SH：生命周期、锁、有限轮次、续录。
- [x] 离线测试、launch 检查、仿真代表样本验证，报告剩余配额。

实际验收：正式80次尝试保存3条（low两条、low_tilt一条），其余仍待录；其他类别暂无成功样本。详见数据目录首轮补录结果.md。
