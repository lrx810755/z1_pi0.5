# 启动对照实验

当前执行环境不能访问主机 ROS/GPU，因此需要在主机终端启动。原场景源码与生产参数文件没有修改，实验通过独立包装器增加临时参数接口。

1. 在原仿真启动终端 Ctrl+C 正常结束当前场景，确认没有另一程序同时控制机械臂。不要同时启动两套场景。
2. 在终端一运行：

```bash
bash /home/lp531/smolvla_eval/grasp_parameter_comparison_20261008/start_scene.sh
```

3. 等仿真图像和 ROS 状态正常后，在终端二运行：

```bash
bash /home/lp531/smolvla_eval/grasp_parameter_comparison_20261008/run.sh
```

脚本先验证实验参数接口及读取当前参数，再执行最多 66 次回放。全程不加载 PI0.5/ACT/SmolVLA 权重，不运行模型推理。九组在相同 seed 下比较，四个场景复测，自动记录三路 MP4、状态、原生结果及更严格放置代理结果。

结果保存在本目录 results_日期时间 子目录：trials.json、recommendation.json、结果报告.md。正常结束或 Ctrl+C 中断时尝试停止动作并恢复实验启动时的夹爪参数，恢复成功写 restored.json；失败写 RESTORE_FAILED.txt。若强制杀进程，恢复逻辑可能无法执行；重新启动普通场景可重建原配置。

默认复测至少 9/12 次满足严格代理才输出候选推荐，否则推荐为空。即使有推荐，仍需检查该组录像，避免把参考点入箱误判为整个瓶子完整入箱。全部候选失败时不自动推荐某个“最佳”失败组合。

这里尚未运行任何物理对照。离线检查只验证脚本和排序规则，不证明运行时参数能正确生效或抓取会成功。
