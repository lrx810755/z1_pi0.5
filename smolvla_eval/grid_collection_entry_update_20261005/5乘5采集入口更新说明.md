# 原5×5采集入口更新

日期：2026-10-05。

## 瓶子固定关闭

按用户要求，共用 GraspAssistant 的瓶子 `pregrasp_target_command` 已由 `freeze` 改为 `unfreeze`。瓶子从接近阶段开始保持动态物理；其冻结定位校正次数为0，因此当前瓶子单次定位流程不会再次固定。保留真实碰撞、重力、跟踪保护与夹持验证。杯子的原模式保持不变。

`freeze_target_keep_collisions:=true` 仅定义收到freeze指令时的碰撞行为，并不自行固定瓶子；不能通过将它改为false来关闭固定。原5×5入口仍使用网格队列和 `continuous_training.py`，没有替换成夹爪微调补录入口。两类入口共用抓取模块，因此瓶子模式变更也适用于其他调用该模块的自动示教入口。

验证：安装环境加载的模块解析到已修改源文件，瓶子接近指令为unfreeze；相关物理配置测试3项与网格入口测试14项通过。没有启动新的采集，也尚未验证关闭固定后的完整抓取成功率。

- 原入口默认新数据目录 `/home/lp531/smolvla_data/z1_tabletop_raw_left_wrist_three_camera_v1`，新日志/进度目录 `/home/lp531/z1_queue_logs/smolvla_left_wrist_three_camera_v1`。不会把旧两路回合计入新采集配额。

- 启动前检查已有目录是否是三路预期形状；不兼容目录会报错，不覆盖旧数据。

- 中断会退出并清理本次场景进程组。

## 保留的原网格行为

仍按5行×5列遍历，目标依次 apple、beverage_bottle、peach、cup；apple/peach第4列沿用原脚本的暂不采集规则。瓶子与杯子各覆盖25格，苹果与桃各20格，合计90个计划组合。

默认每组合8条成功示范，计划总720条；参数2是每组合累计失败上限（默认50）。计数达到配额就跳过；仅补剩余条数，暂时不可达或达到失败上限的组合留到下一轮重试。

## 命令

只采瓶子（第三个位置参数选择物体）：

```bash
bash /home/lp531/start_smolvla_left_wrist_collection.sh 8 50 beverage_bottle
```

瓶子覆盖25格，每格累计8条成功示范，共200条目标；已有同物体、同方格的数据会计入配额，只补剩余条数。物体支持 `beverage_bottle`（瓶子）、`apple`、`peach`、`cup`、`all`，不传则仍为 `all`。各物体共用当前三相机数据目录和进度文件。

通用启动器物体参数位于第7个位置（数据目录、日志目录、腕部话题、none之后）；底层网格队列位于第5个位置（进度文件之后）。单物体模式启动场景时也设为该物体。

采集全部物体：

```bash
bash /home/lp531/start_smolvla_left_wrist_collection.sh 8 50
```

只预览，不启动ROS、不创建数据/日志目录、不采集：

```bash
bash /home/lp531/start_smolvla_left_wrist_collection.sh --dry-run 8 50 beverage_bottle
```
