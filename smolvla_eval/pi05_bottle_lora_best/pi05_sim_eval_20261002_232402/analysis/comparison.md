# 23:24:02 瓶子失败测试与成功示范对照

## 结论

这次失败有两个可重复观察到的问题：接近中段的关节姿态已偏离附近成功示范；模型从张爪主动切换到闭爪的时机不稳定。固定瓶子有效，但未消除上述问题。现有证据不足以将原因归结为某个 LoRA 超参数或腕部相机完全失明。

## 对照对象与方法

失败运行：`pi05_sim_eval_20261002_232402`，seed 882884764，瓶子位置 (0.484977, -0.103913)。93条动作，20.15秒墙钟 / 11.55秒仿真，最终 finger_table_contact，停止前 frozen=true。

从实际使用的 prepared 数据集中按瓶子初始 XY 距离选择最近的三条成功示范，均属于训练集：

| prepared episode | 距离 | 来源类型 | 第一次闭爪命令帧 |
|---|---:|---|---:|
| 000089 | 11.08 mm | baseline | 119 |
| 000235 | 15.74 mm | high | 117 |
| 000053 | 19.81 mm | baseline | 106 |

各示范 task_success=true。不同场景中的杯子等干扰物布局不同，因此这是附近成功轨迹对照，不能当作相同场景的因果实验。

使用关节2的接近进度匹配成功示范首次闭爪前的最近帧，避免直接按墙钟时间比较。关节2后段存在回退，匹配不是严格单调；此方法用于定位明显姿态差异，不表示两帧具有相同末端位置。视频索引按 rollout 写入逻辑恢复：每5条动作前另写1帧规划观测，93条动作对应112帧。录像没有完整观测时间戳，不能保证像素级时间同步。

## 1. 姿态偏差发生在闭爪之前

| 失败 trace 索引（从0开始） | 墙钟时间 | 相对三条示范的关节4角度差 |
|---:|---:|---|
| 15 | 4.97 s | 2.3°, 4.1°, 3.3° |
| 28 | 7.32 s | 10.4°, 19.7°, 17.0° |
| 45 | 10.70 s | 19.3°, 36.1°, 31.4° |
| 60 | 13.63 s | 23.5°, 46.5°, 41.5° |

定义“明显偏差”为关节4差异超过10°并持续至少5条记录。相对三条示范分别在6.07、6.50、7.32秒达到该标准；7.32秒时三者均满足。10°是本次分析阈值，不是机器人安全阈值，也不是精确的故障起点。

最终失败姿态与三条成功示范闭爪姿态：

- 关节4：失败 −14.93°；成功 −58.90°～−60.84°，差约44～46°。
- 关节6：失败 −139.07°；成功 −110.56°～−111.63°，差约27～29°。
- 不能把单关节差直接解释成末端转角。使用本地 URDF 正运动学得到最终末端相对成功闭爪姿态的整体旋转差约15.4～15.8°；此处没有声称计算了仿真世界中的精确末端位置或接触。

本次只有索引18、42、90的3条动作受到限幅修改。按下一条关节观测与上一条发送命令比较，六关节绝对误差中位数分别0.01、0.04、0.27、0.16、0.15、0.04°，最大约1.24°。该近似跟随检查支持主要偏差来自策略命令，而非机械臂大幅拒绝执行；并不等于高频伺服误差测量。

## 2. 同一模型的重复离线推理

加载实际测验使用的108000 checkpoint及同一预处理/后处理，在12个输入上各随机采样5次，共60次推理，没有向机器人发送命令。

| 输入 | 真实闭爪偏移 | 5次预测闭爪偏移（帧） |
|---|---:|---|
| demo89 frame114 | 5 | 12,20,3,13,25 |
| demo235 frame112 | 5 | 15,21,3,22,19 |
| demo53 frame101 | 5 | 23,30,14,28,17 |
| demo89 frame119 | 0 | 0,0,0,0,0 |
| demo235 frame117 | 0 | 0,0,0,0,2 |
| demo53 frame106 | 0 | 0,0,0,0,0 |
| 失败 trace75 | 未闭爪 | 50帧内均未闭爪 |
| 失败 trace90 | 未闭爪 | 50帧内均未闭爪 |

闭爪前5帧的15次推理有13次推迟，预测偏移中位数17帧；真实偏移为5帧。开始闭爪的输入15次全部在前5帧继续闭爪，但这些输入的实际夹爪状态已经从−0.90变化到−0.747/−0.789/−0.783，因此它证明的是“能延续闭爪”，不能证明“能从完全张开自主发起闭爪”。

失败录像重放使用压缩后的双相机帧，属于近似离线重放，不是原始观测逐字节复现；随机推理未固定种子。后段10次都未在未来50帧预测闭爪，说明单纯把执行窗口从5帧延长，在这些样本上也没有现成闭爪动作可执行。

成功示范中段输入的前5帧各关节平均绝对误差约0.5～2.0°；单次离线动作拟合较好，仍不能保证自主滚动后留在成功轨迹附近。

## 3. 数据中值得关注的等待段

三条成功示范在闭爪前，手臂六关节已分别有2.9、3.0、2.9秒保持在闭爪姿态各关节±0.01 rad范围内。腕部画面也非常相似，夹爪直到末段才开始关闭。

当前策略 n_obs_steps=1，未启用视觉或本体历史。长时间近似相同的观测既对应等待又接近闭爪转换，可能让“何时开始闭爪”难以学习。此为数据和配置共同支持的待验证解释，不是已通过消融确定的根因；局部推理中模型在夹爪已经开始改变时表现更好，与该解释一致。

## 建议

1. 优先评估接近中段关节4/6与末端姿态的偏差，以及从完全张爪主动发起闭爪的能力。
2. 下一次训练可通过采样权重强调接近姿态调整和闭爪转换；保留所有中间帧，不通过裁剪等待段解决。
3. 不建议根据本轮结果直接放宽触桌保护、强制按时间闭爪或单纯延长执行窗口。尚未验证这些变化能形成有效抓取。
4. 暂不把 rank 或训练步数认定为根因；应在相同场景条件下做参数/采样方案对照，并以抓取结果选模型。
