# PI0.5 验证输入时间戳同步修复

日期：2026-10-05。已修改生产验证程序，使用原 SH 命令重新启动即可生效。已运行的旧进程需要退出后重启。

## 修改

- 相机及关节消息按 ROS header 中的仿真时间戳缓存，选择最新的合格配对；关节使用同一时间的实测值或两侧实测值插值，插值跨度最多 100 ms。
- 两个相机与目标关节时刻的最大跨度默认 25 ms；最旧选中输入相对最新关节仿真时刻最多 200 ms；已用图像不重复送入下一次预测。
- 最多等待 500 ms 墙钟时间，找不到合格输入时停止本次验证。停止先发布当前关节位置保持命令并关闭策略控制，再处理可能等待 ACK 的解除冻结。
- 运动限步、跟踪误差、接触保护继续读取最新关节反馈。所有时间戳倒退的关节消息被拒绝，防止 DDS 延迟消息回滚保护反馈。若重置整个仿真时钟，应重新启动验证进程；这里没有自动恢复全局时钟重置。
- 每次预测记录实际选中时间戳、关节插值区间、输入状态、配对误差、输入年龄、等待时间；解除冻结失败单独记录 cleanup_error，保留原始停止原因。
