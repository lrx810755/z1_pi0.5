# 杯子穿透：根因、修复与继续查验

已确认并修复的主要问题是 RGB 渲染遮挡错误：玻璃杯明明位于不透明夹爪后方，实时渲染却把杯身和杯内内容叠到夹爪前。此前仅凭第18次某个桌面画面解释为视觉误判，不能覆盖用户指出的其他片段；Trial 05、08 等确实存在可复现的渲染错误。

## 原因与因果验证

场景使用 RTX RaytracedLighting。`/rtx/translucency/worldEps` 的原始值为 `1.0`。NVIDIA 将它定义为切换到基于图像的折射重投影近似的阈值，降低阈值会提高准确度。在本场景的厘米尺度近距离抓取中，这条近似渲染路径产生了错误的前景遮挡。

官方参数说明：[RTX Real-Time Legacy / Translucency](https://docs.omniverse.nvidia.com/materials-and-rendering/latest/rtx-renderer_rt_legacy.html#translucency)。

同一场景、同一杯子及机械臂位姿、相同原始材质：

| 控制条件 | 结果 |
|---|---|
| 原始实时渲染，worldEps=1.0 | RGB 显示杯身覆盖前景夹爪，深度/语义结果却显示前景为机器人 |
| 仅改 worldEps=0.0001 | RGB 恢复前景夹爪对杯子的遮挡，保留玻璃外观 |
| 仅改 worldEps=0.0 | 同样恢复遮挡 |
| 将玻璃换成 OmniGlass、保留原阈值 | 仍复现，单独换玻璃材质不能解决 |
| 使用路径追踪参考 | 正确遮挡，与调小阈值后的实时渲染一致 |
| 强制杯子不透明（仅诊断） | 正确遮挡，但改变外观，因此没有作为修复方案 |

这解释了“两者未接触，腕部图像却像穿模”：错误发生在 RGB 折射重投影与前景合成，并不需要物理碰撞发生，也不是允许机械臂透视。两指视觉网格与原始碰撞网格逐顶点差异仅约 0.00013 毫米和 0.00010 毫米；杯子视觉表面对当前倒圆台碰撞体的最大径向外伸约0.36毫米，均不能解释所见的大面积杯身透视。

## 已落地修改

- 新增 `isaac_assets/z1/scripts/render_occlusion.py`，统一设置 worldEps=0.0001。
- 通用 `run_z1_ros2_scene.py` 与当前杯子独立场景 `run_cup_only_scene.py` 均调用此设置。
- 设置在第一次预热渲染之后应用。测试发现仅在渲染器初始化之前设置不足以稳定生效，已验证初始化顺序。
- 两个实际入口均完成启动及短时运行检查，日志确认阈值为0.0001，无错误日志。
- 保留原玻璃材质、相机位置、近裁剪、机械臂、杯子碰撞体和控制策略。
- 当前杯子独立场景 USD 的 SHA256 仍为 `547b0902f99ea4aa537282fdbcfb57c6576f7697b3f1e3bb36fe434319b1509a`，资产内容未改动。

源文件修改备份位于 `fix_backup/`，差异位于 `fix_changes.diff`。当前评估目录的 `render_fix_20261026.json` 记录历史结果与后续运行的区别。

## 静态与动态验证

像素回归检查针对“深度证明杯子被机器人挡住”的区域，将 RGB 与单独渲染机器人时的 RGB 对照；明显差异定义为任一颜色通道相差超过30/255。它是本问题的诊断指标，不是模型成功率。

| 固定位姿 | 被遮挡区域像素数 | 修复后明显差异像素占比 |
|---|---:|---:|
| Trial 02，约56.98秒 | 18,120 | 0.061% |
| Trial 05，约56.93秒 | 12,610 | 0.381% |
| Trial 08，约56.97秒 | 16,977 | 0.112% |

Trial 05 修复前同一指标为73.74%，修复后为0.381%；修复后差异主要位于边缘，差异中位数均为1/255。回归先在旧设置下明确失败，再在实际修复函数下通过。

继续完成了520组记录位姿的前后重放，三视角、104秒轨迹，共3120幅视角画面。范围为 Trial 02 的30–60秒、05的30–60秒、08的24–60秒、12的24–32秒。已复查动态抽帧，原先大面积透视未再出现。Trial 12 后半段杯子已离开腕部视野，不把该阶段当作腕部渲染错误的正例。

动态重放只验证相同记录轨迹的显示效果，没有重新运行 ACT 推理或重新进行物理测评，不能据此宣称成功率提高。现存训练/评估视频中的历史伪影不会自动消失；此修复作用于后续仿真渲染。

## 尚存在的真实物理穿入

原评估接触记录中，杯子与手指碰撞体仍有少量真实负间距：

| Trial | 原始记录最大穿入 |
|---|---:|
| 05 | 未记录到手指接触 |
| 08 | 约0.030毫米 |
| 12 | 约0.036毫米 |
| 15 | 约0.983毫米 |
| 16 | 约1.658毫米 |
| 23 | 约1.125毫米 |
| 28 | 约3.853毫米 |

第28次峰值发生在约41.68秒：杯子仍接触桌面、双指均有接触，夹爪目标持续要求闭合；杯子速度约0.100米/秒。此时实际夹爪角约-0.511弧度，命令仍向-0.411推进。碰撞保持开启、杯子未冻结。约41.80秒记录已回到约0.097毫米。现有数据定位到持续闭合及接触挤压阶段，但没有单独验证求解器或刚度的根因，不能把这一部分说成已解决。

这些值仅覆盖杯子与手指碰撞体的已记录接触，不能证明整个机械臂不存在任何穿入。本次修改未调整物理参数，也没有用材质变化掩盖物理接触。
