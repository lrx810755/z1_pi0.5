# 多物体与单目标训练差异分析（2026-09-29）

## 结论

现有证据支持“模型已学到一部分目标定位，但完整抓取/放置链条仍不稳定”，尚不支持“单目标已在自动评估中稳定成功、多物体完全不会定位”的强结论。用户现场观察到单目标 SmolVLA 和 ACT 基本能定位、尝试抓取；自动评估使用更严格的物理成功条件，瓶子单目标与多物体样本都没有完成完整抓取放置。多物体问题很可能同时包含每目标训练曝光不足、不同物体动作混合造成的策略干扰，以及评估环境缺陷；仅凭当前记录无法给三者分配确定权重。

## 最可能的解释与验证顺序

1. **每目标有效训练曝光不同。** 混合训练的每个 batch 包含四类目标，苹果和桃子的有效更新更少。已经挂载的杯子、苹果、桃子专训沿用瓶子参数（batch 8、30,000 步、同相机和动作窗口），可直接检验“专训改善是否来自减少目标混合”。训练 loss 只能反映拟合，不能代替仿真成功率。
2. **不同物体的动作规律冲突。** 瓶子、杯子、苹果和桃子的形状、夹爪接近角、闭爪位置、抬升和搬运轨迹不同。混合模型在同样状态附近必须依据视觉和任务文本选对模式。下一步应对相同测试种子，记录目标中心与夹爪轨迹误差、首次闭爪位置、双指接触、离桌高度和放置结果，定位“选错目标”还是“目标对了但抓取动作错”。
3. **仿真评估本身仍是干扰项。** 已记录相机空白、夹指碰桌、关节跟踪故障、瓶子物理飞出和旧进程状态协议不一致。应固定场景版本、相机、随机种子和停止规则，再做每类至少 20 次配对评估。训练故障与场景故障要单独统计。

## 比较标准

用相同数据集版本、相同种子和同一仿真版本比较多物体检查点与三个专训检查点；分别报告定位到目标的比例、正确闭爪位置比例、双指有效接触比例、离桌比例、最终放置成功率。只有当专训在这些分阶段指标上稳定高于混合模型，才能把问题主要归因于多目标策略学习，而不是现有评估链路。
