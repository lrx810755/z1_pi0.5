# 桌面透明物体折射遮挡修复

本次沿用杯子已验证的 RTX 修复，将 `/rtx/translucency/worldEps` 统一为 `0.0001`。此值是折射近似切换阈值，不是材质折射率 IOR。

## 逐物体检查

检查了通用桌面场景中可见几何实际绑定的材质：

| 物体 | 透明材质 | 本次处理 |
| --- | --- | --- |
| 杯子 | Glass、Condensation，opacity=0.25 | 保留原材质，继续使用全局修复 |
| 饮料瓶 | BotellaSt、GotasSt，opacity=0.25；RefrescoSt，opacity≈0.4617 | 纳入同一全局修复 |
| 苹果 | 不透明 | 核验，无须修改材质 |
| 桃子 | 不透明 | 核验，无须修改材质 |
| 鼠标 | 不透明 | 核验，无须修改材质 |
| 桌面、蓝盒 | 不透明 UsdPreviewSurface | 核验，无须修改材质 |

材质清单见 `bound_material_audit.json`；源资产中有 MaterialBindingAPI 未显式应用的兼容性警告，但 USD 能解析实际材质绑定。本次没有修改此独立问题。

## 落地范围

- ROS 工作区通用启动入口已经在首帧预热后应用全局修复，所有目标物体共用此设置。
- 为旧路径 `/home/lp531/isaac_assets/z1/scripts/run_z1_ros2_scene.py` 补齐相同初始化顺序和设置。

- 为 6 个现有任务场景写入 Kit 的 `customLayerData.renderSettings["rtx:translucency:worldEps"]`。完整路径见 `verification.json`。
- 保留已修复的杯子独立运行入口，其调用方式未改变。

本次没有调整材质 IOR、透明度、纹理、碰撞体、物体尺寸或机械臂参数。几何和物理设置无变化，不能将本次修复解释为解决真实物理穿入。
